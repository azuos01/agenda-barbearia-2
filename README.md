# Agenda da Barbearia

Agenda de horários de uma barbearia: cadastra corte, barba ou combo
e impede horários sobrepostos ou fora do expediente (09:00 às 19:00).

## Como rodar
1. Instale o Node.js 20 LTS ou superior.
2. Copie `.env.example` para `.env`.
3. `npm start` e abra http://localhost:3000

## Como testar
`npm test`
